# Public test boundary

Keep this repository public-safe and standalone. Never copy private SOMA source,
archives, keys, raw evidence or benchmarks here. No private checkout, tokens,
secrets, inference, model downloads, paid/large/self-hosted runners or elevated
privileges. Do not change settings, permissions or visibility. Changes require a
reviewable development branch and PR; do not merge automatically.

Report actual executed checks separately from source inspection and blocked
capabilities. Preserve failed runs. Do not treat these synthetic fixtures as
production security verification.
